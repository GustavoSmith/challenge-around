# Challenge Around - Media Player

La evaluación consiste en la implementación de un media player con su funcionalidad básica por default y funcionalidad extendida que es detallada en los puntos a continuación.

El media player deberá cargar un video mp4 con audio.

Implementación:

1. Crear y configurar el proyecto web en React
2. Implementar una UI básica para el reproductor y sus acciones (custom o utilizando una librería de componentes a elección)
3. Utilizar una librería para reproducir el video proporcionado.
4. El reproductor deberá mostrar como información básica la duración y el timecode de reproducción actual.
5. Implementar controles básicos del reproductor:
   1. Play, Stop, Pausa, Volumen
   2. Fast Forward (Acelerar la velocidad de reproducción):
      1. en velocidades 2x, 4x, 8x, 16x.
6. Publicar el proyecto para poder acceder de forma externa y poder reproducir la media utilizando el player implementado con todas sus funciones.

Deseable:

1. Fast Forward custom en velocidades 32x,64x
2. Backwards custom en velocidades -2px, -4px, -8px, -16x
